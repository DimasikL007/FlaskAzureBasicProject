Хмарні сервіси надають обчислювальні ресурси, платформи та готові програми через інтернет. Модель послуги визначає, чим керує користувач і що обслуговує постачальник.

Від інфраструктури до готового застосунку
{{ icon('server') }}01 / Інфраструктура

IaaS

Infrastructure as a Service

Інфраструктура як послуга

Обчислювальні ресурси на вимогу: віртуальні машини, сховища та мережі для власних систем.

Постачальник
Обслуговує фізичне обладнання та рівень віртуалізації.
Користувач
Установлює й обслуговує операційну систему, середовище виконання та застосунки. Керує даними й налаштуваннями доступу.
  • Значний контроль над середовищем, але потрібні навички адміністрування.
  • Для власних серверів, нестандартних конфігурацій і перенесення наявних систем у хмару.
Приклади сервісів

Azure Virtual Machines · Amazon EC2

{{ icon('layers') }}02 / Платформа

PaaS

Platform as a Service

Платформа як послуга

Готове середовище для розроблення, запуску та розгортання власних застосунків.

Постачальник
Обслуговує інфраструктуру, віртуалізацію, операційну систему та підтримуване середовище виконання.
Користувач
Керує кодом, залежностями, даними та налаштуваннями застосунку.
  • Простіше розгортання та менше адміністрування. Доступ до базового середовища обмежений можливостями платформи.
  • Для вебзастосунків, API та команд, які зосереджуються на розробленні.
Приклади сервісів

Azure App Service · Google App Engine

{{ icon('app') }}03 / Програма

SaaS

Software as a Service

Програмне забезпечення як послуга

Готовий застосунок, доступний через інтернет у браузері або клієнтській програмі.

Постачальник
Обслуговує інфраструктуру, середовище виконання та сам застосунок, забезпечує його оновлення.
Користувач
Працює з функціями сервісу. Керує власними даними, обліковими записами, доступами та доступними налаштуваннями.
  • Початок роботи без розгортання власного застосунку. Налаштування залежать від функцій сервісу.
  • Для роботи з документами, комунікації, спільної роботи та готових бізнес-завдань.
Приклади сервісів

Microsoft 365 · Google Docs
